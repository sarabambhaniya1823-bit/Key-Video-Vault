---
name: Little Reel storage scope
description: The user's chosen storage and access scope for the private video library.
---

Little Reel is intentionally a local-only demo: videos stay in the browser on the current device, and viewers do not need an account sign-in. The user chose this instead of shared storage.

**Why:** The user selected a local-only demo after learning that shared storage would require sign-in and would make videos available across devices.

**How to apply:** Keep video storage device-local and do not add cloud syncing or mandatory account sign-in unless the user explicitly changes this choice.
